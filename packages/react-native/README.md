# @yldm-tech/ai-logo-rn

`React Native`

Popular AI / LLM model brand icons for React Native and Expo, generated from the same sources as [`@yldm-tech/ai-logo`](https://www.npmjs.com/package/@yldm-tech/ai-logo).

## Status

**This package is not published.** It is marked `private` and exists in the repository as a maintained-in-place port rather than a release artifact.

It builds (`pnpm --dir packages/react-native run build`) and type-checks, and CI type-checks it on every pull request so it cannot silently rot against `src/`. What it does not have is a test suite or a release pipeline, and its icon set is regenerated by hand through `scripts/rn-conversion` rather than on every change — so it can sit behind `src/` until someone runs the conversion.

If you need these icons on React Native today, the honest options are to vendor this directory or to render the static SVGs from [`@yldm-tech/ai-logo-static-svg`](https://www.npmjs.com/package/@yldm-tech/ai-logo-static-svg) through `react-native-svg` yourself.

Publishing it is a decision that has not been made. Making it publishable means adding tests, wiring the conversion into CI so the port cannot drift, and adding a publish step to `.github/workflows/release.yml`.

## Regenerating from src/

```bash
pnpm run auto-converter-web-icons-to-rn
```

That walks `src/`, rewrites each web component for `react-native-svg`, and syncs the feature configs. Review the diff before committing — the converter is code generation, not a build step.
