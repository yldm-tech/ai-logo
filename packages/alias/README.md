# ai-logo

Popular AI / LLM model brand SVG logo and icon collection for React.

**This package is an alias.** It contains one line — `export * from "@yldm-tech/ai-logo"` — and depends on that package at the matching version. Installing it gets you the real thing, so `import { OpenAI } from "ai-logo"` works exactly as it reads.

The canonical name is [`@yldm-tech/ai-logo`](https://www.npmjs.com/package/@yldm-tech/ai-logo). Prefer it in new code: it is the package that is actually built and released, and it is the name the documentation uses.

```bash
npm i @yldm-tech/ai-logo
```

Everything — the icon list, usage, CDN links, the component API — is documented in the [main README](https://github.com/yldm-tech/ai-logo#readme) and at [ailogo.yldm.ai](https://ailogo.yldm.ai).
